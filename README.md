# FizzBuzz+

A Python project developed for PROG 1003 – Programming Logic 1.

## Overview

FizzBuzz+ processes a user-defined range of integers and evaluates each number based on whether it is divisible by 3, 5, both, or neither. Depending on the result, the program performs additional mathematical calculations.

## Features

- Accepts a user-defined range of integers
- Validates range limits and user input
- Uses loops and conditional logic to classify numbers
- Calculates cube roots, base-10 logarithms, and degree-to-radian conversions
- Handles non-integer input with exception handling

## Technologies

- Python 3
- Python `math` module

## How to Run

1. Install Python 3.
2. Open a terminal in the project folder.
3. Run the program using:

   `python fizzbuzz.py`

Replace `fizzbuzz.py` with your actual Python filename if necessary.

## Background

Created as a coursework assignment for PROG 1003 – Programming Logic 1 at Northwest Arkansas Community College.
